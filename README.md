## 🚀 How to Run & Deploy

### Quick Local Preview
Simply double click `index.html` or open it with any web browser (Chrome, Brave, Edge, Firefox, Safari).  
Everything is self-contained with CDN assets and requires **zero build steps** or Node dependencies.

### Instant Cloud Deployment
To host the site live:
1. **GitHub Pages**: Push this directory to a GitHub repository and turn on GitHub Pages in repository settings.
2. **Vercel / Netlify**: Drag and drop the `vastushed-website` folder directly into the Netlify or Vercel dashboard. It will go live immediately on a custom HTTPS URL.
